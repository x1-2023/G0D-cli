# G0D-cli

G0DM0D3 Coding Edition — multi-provider, multi-model coding agent extending Grok Build.

## Features (in progress)

- **GODMODE CLASSIC**: 5-model parallel racing with persona-preset candidates
- **ULTRAPLINIAN**: 5-tier multi-model evaluation (12-60 models)
- **Parseltongue**: 33 input perturbation techniques for red-teaming
- **AutoTune**: 20-context adaptive parameter engine
- **Multi-provider**: Grok, OpenRouter, Venice, OpenAI-compatible local
- **Privacy**: Local-only mode, no-log mode, telemetry off by default
- **Race UI**: Candidate comparison, scoring, tournament judging
- **Multimodal**: Image input support
- **Cost controls**: Token/cost budgeting and preview

## Based on

- [grok-build](https://github.com/xai-org/grok-build) by xAI
